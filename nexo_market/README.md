# Nexo Market — Tienda virtual de productos variados

Proyecto  de interfaz web.

## Cómo ejecutar
1. Descarga o clona este repositorio.
2. Abre `index.html`.
3. Para local recomendo, abrir la carpeta en Visual Studio Code y utilizar Live Server.

## Funcionalidades
- Catálogo de ocho productos de categorías variadas.
- Filtros por categoría, búsqueda y ordenamiento por precio.
- Carrito lateral con cantidades, subtotal y mensajes de demostración.
- Menú móvil, formulario de suscripción y navegación por secciones.
- Diseño adaptable a escritorio, tableta y teléfono.

## Estructura
- index.html: estructura semántica y contenido.
- css/styles.css: estilos, Flexbox, Grid y media queries.
- js/app.js: catálogo, filtros, búsqueda y carrito.
- img/: recursos gráficos locales del proyecto.
- evidencias/: capturas de las vistas responsive.
- documentacion.pdf: memoria descriptiva del proyecto.
